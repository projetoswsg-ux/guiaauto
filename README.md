# 📰 Meu Blog de Notícias

Blog moderno construído com Astro + Markdown, hospedado no Vercel.

## 🚀 Como publicar uma notícia

1. Crie um arquivo em `src/content/noticias/nome-da-noticia.md`
2. Adicione o cabeçalho:

```yaml
---
title: "Título da notícia"
description: "Resumo curto"
pubDate: 2026-05-19
author: "Seu nome"
category: "Brasil"
image: "https://link-da-imagem.jpg"
---
